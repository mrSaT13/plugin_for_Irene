## ✨ Возможности

### 🏠 Управление устройствами
- ✅ **Включение/выключение** — "хаб включи свет", "хаб выключи телевизор"
- ✅ **Управление по комнатам** — "хаб выключи свет в гостиной"
- ✅ **Таймеры** — "хаб выключи через 5 минут"
- ✅ **Умный поиск** — автоматическое распознавание синонимов устройств

### 🌡️ Климат-контроль
- ✅ **Температура** — "хаб какая температура", "хаб температура в спальне"
- ✅ **Настройка температуры** — "хаб установи температуру 22 градуса"
- ✅ **Комфорт** — "хаб холодно" (сделать теплее), "хаб жарко" (сделать холоднее)
- ✅ **Кондиционер** — "хаб вентиляция", "хаб шторки вверх/вниз"

### 🧠 Умные функции
- ✅ **Автоматическое определение комнат** из названий устройств
- ✅ **Маппинг типов устройств** (гирлянда = свет, колонка = медиа)
- ✅ **Кэширование** — быстрая работа с периодическим обновлением
- ✅ **Локальная работа** — все запросы в вашей сети

## 📦 Установка

### Шаг 1: Копирование плагина

```bash
cp plugin_ha_bridge.py ~/.irene/plugins/plugin_ha_bridge/plugin_ha_bridge.py
```

### Шаг 2: Перезапуск Ирины

Перезапустите голосовой ассистент для загрузки нового плагина.

### Шаг 3: Настройка через веб-интерфейс

1. Откройте веб-интерфейс Ирины: **http://your-irene:8086**
2. Найдите раздел конфигурации `ha_bridge`
3. Заполните параметры:

| Параметр | Описание | Пример |
|----------|----------|--------|
| `ha_url` | URL вашего Home Assistant | `http://192.168.1.100:8123` |
| `ha_token` | Long-Lived Access Token из HA | `eyJ0eXAi...` |
| `refresh_interval` | Интервал обновления устройств (сек) | `300` (по умолчанию) |

## 🔑 Создание токена Home Assistant

<div align="center">

**Важно:** Токен дает полный доступ к вашему Home Assistant. Храните его в безопасности!

</div>

1. Откройте **Home Assistant** в браузере
2. Кликните на **профиль пользователя** (внизу левой панели)
3. Прокрутите вниз до раздела **"Долговременные токены доступа"**
4. Нажмите **"Создать токен"**
5. Введите название: `Irene HA Bridge`
6. Скопируйте сгенерированный токен
7. Вставьте токен в настройки плагина Ирины

## 💬 Команды управления

### 🎛️ Основные команды

| Команда | Пример |
|---------|--------|
| Включить устройство | `хаб включи свет` |
| Выключить устройство | `хаб выключи телевизор` |
| Управление в комнате | `хаб включи свет в гостиной` |
| Таймер выключения | `хаб выключи через 5 минут вентилятор` |

### 🌡️ Климат и комфорт

| Команда | Пример |
|---------|--------|
| Узнать температуру | `хаб какая температура` |
| Температура в комнате | `хаб температура в спальне` |
| Установить температуру | `хаб установи температуру 22` |
| Проветрить | `хаб вентиляция` / `хаб проветрить` |
| Сделать теплее | `хаб холодно` |
| Сделать холоднее | `хаб жарко` / `хаб душно` |
| Управление шторками | `хаб шторки вверх` / `хаб шторки вниз` |

### ℹ️ Информация и справка

| Команда | Описание |
|---------|----------|
| `хаб обнови устройства` | Принудительно обновить список устройств |
| `хаб список устройств` | Показать все доступные устройства |
| `хаб какие комнаты` | Список обнаруженных комнат |
| `хаб что включено` | Показать активные устройства |
| `хаб помощь` | Справка по командам |
